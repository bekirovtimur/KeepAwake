<h1 align="center">KeepAwake</h1>

<p align="center">Крошечная утилита для Windows, которая не даёт компьютеру уснуть во время долгих задач</p>

<p align="center">
  <b>Русский</b> · <a href="README.en.md">English</a>

## Что делает скрипт

KeepAwake предотвращает засыпание компьютера при выполнении долгих задач — рендеринге видео, копировании файлов, загрузках, компиляции и любой другой работе, которую нельзя прерывать.

Скрипт написан на [AutoIt v3](https://www.autoitscript.com) и работает так:

- раз в секунду проверяется время простоя системы с помощью функции `_Timer_GetIdleTime()`;
- если в течение **10 секунд** не было нажатий клавиш и движений мыши, курсор сдвигается на 1 пиксель и тут же возвращается на место;
- это сбрасывает таймер простоя Windows — система считает пользователя активным и не блокирует экран и не засыпает посреди работы.

## Как использовать

1. Скачайте сборку под вашу ОС: **Windows x86** или **Windows x64**.
2. Запустите `KeepAwake.exe`. Установка не требуется — утилита висит в трее возле часов и тихо работает в фоне.
3. Чтобы остановить её, кликните мышью по иконке скрипта в трее и закройте его в открывшемся меню.

## Сборка из исходников

Весь исходный код — это один файл `keepawake.au3`. Каждый желающий может внести правки и скомпилировать скрипт самостоятельно:

1. Скачайте и установите [AutoIt v3](https://www.autoitscript.com) (полная установка включает компилятор).
2. Внесите в `keepawake.au3` любые изменения.
3. Скомпилируйте его в самодостаточный exe-файл с помощью **Aut2Exe – Script to executable converter** — через меню «Пуск» (*AutoIt v3 → Compile Script to .exe*), через правый клик по файлу `.au3` в Проводнике (*Compile Script*) или из командной строки:

   ```
   Aut2Exe.exe /in keepawake.au3 /out KeepAwake_x64.exe /icon media\icon.ico /x64
   Aut2Exe.exe /in keepawake.au3 /out KeepAwake_x86.exe /icon media\icon.ico /x86
   ```
